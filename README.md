# InSituCNV


Coming soon - Repository for running `insituCNV` on image-based spatial transcriptomics data, demonstrated using an example dataset.


The code to reproduce the results from the manuscript ***In Situ* Inference of Copy Number Variations in Image-Based Spatial Transcriptomics** by Jensen et al., bioRxiv (2025), https://doi.org/10.1101/2025.07.02.662761, can be found here: https://github.com/Moldia/InSituCNV-manuscript
